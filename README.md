# 🚆 Railway Management System

A professional **Railway Management System** developed using **Python** and **MySQL Database** with voice assistant integration.  
This project helps manage passenger information, train details, database operations, and customer support functionalities efficiently.

---

# ✨ Features

- Add New Passenger Details
- Add Train Information
- Passenger Details Checking
- Train Details Checking
- MySQL Database Integration
- Voice Assistant Support
- Speech Recognition System
- Customer Support Functionality
- Interactive Console Interface

---

# 🛠 Technologies Used

- Python
- MySQL
- Pandas
- SpeechRecognition
- Pyttsx3
- Datetime Module
- Jupyter Notebook / VS Code
